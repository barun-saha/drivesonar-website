Why I built it

My pain point was simple: Windows had no insightful disk usage analyzer with ncdu-style minimalism that also runs without admin privileges.

Every time I hit a space crisis, the native storage settings left me confused about what was actually taking up the disk.

— Barun Saha, author of Drive Sonar

What it does

Open source, with no telemetry in the app.

User-mode scans

Runs fast without admin elevation, with read-only access to the file system.

Space map, file types, age

A treemap of what fills the disk, a breakdown by file type, and size-vs-age plots that surface large files untouched for years.

Careful cleanup

Open items in your file manager, or move clutter to the Trash behind confirmation prompts and safety checks.

Reports

Export point-in-time storage breakdowns to text files, to audit space and track growth.

[1] Admin requirement: WizTree requires administrator privileges to read the NTFS Master File Table directly for its full-speed mode; without elevation it falls back to a slower standard directory scan. WinDirStat (non-admin mode) and Drive Sonar run in standard user mode without elevation.

[2] Peak memory: Private memory of every process the app runs, as shown in Task Manager's Memory column. Drive Sonar is the scan engine (about 120 MB) plus the Microsoft WebView2 runtime that draws its interface (about 200 MB). WinDirStat and WizTree are single native processes. Sample size: Drive Sonar n=34 (all scans); WinDirStat and WizTree n=5.

[3] Warm scan: Repeated scans without rebooting. Median and range of 5 runs for WinDirStat and WizTree, and of 27 runs over 7 sessions for Drive Sonar. Each Drive Sonar session of 5 runs has a median of 4.5–4.8 s.

[4] Cold scan: Median and range of 7 scans for all three, each after a full power-off with the disk idle beforehand. Cold times vary widely on every tool, because background disk activity can make any single cold scan much slower. WizTree was run elevated (MFT mode).

[5] Platform support: Drive Sonar runs natively on Windows, Linux, and macOS. WinDirStat and WizTree support Windows only. Disk scanning speed is optimized for Windows.

Frequently asked questions

Is Drive Sonar open source and free?

Yes. It is free and open source under the Apache 2.0 license. You can read, audit or fork the code on GitHub.

How fast are repeat scans?

Drive Sonar uses multithreaded directory traversal written in Rust. When your OS already has the directory metadata cached in RAM, a re-scan of 1.2M+ files takes a median of 4.7 s here, against 8.1 s for WizTree and 9.4 s for WinDirStat. Details are in the benchmark table.

How does the size-vs-age plot help free up space?

A treemap only shows size, so an active 50 GB folder looks the same as a forgotten one. The plot puts file size on one axis and time since last modification on the other, so large files nobody has touched in years stand out.
